## 1. 验证手段（三层）

| 层 | 工具/脚本 | 覆盖 |
|----|-----------|------|
| 后端逻辑与接口 | `scripts/smoke_e2e.py`（Flask test client，**94 项断言**） | 导入/抽取/校对/入库/导出/设置/知识库/相似/简历/模拟全链路 |
| 真实服务联通 | `python run.py` + HTTP 请求（curl / urllib） | 页面 200、接口状态码、下载响应头、无 500 静默错误 |
| 界面渲染 | `scripts/screenshot_ui.py`（Chrome headless 截图 + DOM dump）+ `scripts/ui_audit.py`（PIL 像素审计） | 10 个页面 × 浅色/深色/移动端 = 30 张截图；关键元素存在性；布局与对比度客观指标 |

**沙箱说明（如实记录）**：
- Playwright 无法使用（沙箱拒绝子进程管道，`WinError 5`），改用系统 Chrome 的 `--headless --screenshot` / `--dump-dom`（stdio 继承，无需管道）；
- Chrome 启动仍需放宽沙箱权限（本会话中经批准的 `danger-full-access` 一次性执行）；
- **当前模型不支持读图**，因此"看界面"改为**程序化审计**：像素级指标 + DOM 断言，避免"声称看过但没看"。

## 4. 后端断言覆盖（94 项，摘录关键项）

- **导入与字段**：新字段落库、时长容错（`1小时30分 → 90`）、标题五级规则、重复导入 409 与强制导入；
- **红线**：修正后 `extract_text` 不被改写、导出分节、原文区间引用、合并不改写机器提取文本；
- **抽取健壮性**：连续追问不丢题、无标签文本可抽取且标待确认、角色不全明确报错、0 问答不静默成功；
- **校对**：删除（软删除）/ 合并下一条 / 拆分 / 全部确认；
- **R3 频次**：同知识点跨场去重、`ask_times` 与出处场次累积；
- **Phase 5 设置**：主题直出、模式热生效（切换后 `/api/analyze` 立即反映）、非法值 400、Key 掩码且响应不含明文、`data/secrets.json` 不可经 HTTP 访问、原子落盘、恢复默认；
- **Phase 6 知识库**：反问 `direction=reverse`、专题归类、一级分类、相似识别与落库、对比页、最佳作答、取消关联；
- **Phase 7 模拟**：简历 txt/docx/PDF、三种出题模式、作答与进度、报告渲染、TTS 探测、会话删除。

## 5. 复现步骤

```bash
# 1) 后端全链路
python scripts/smoke_e2e.py            # 期望：共 94 项断言，通过 94

# 2) 演示数据（可选，会清空 data/）
python scripts/dev_seed.py

# 3) 启动服务
python run.py

# 4) 界面截图 + DOM 校验（需本机有 Chrome/Edge；沙箱环境需放宽权限）
python scripts/screenshot_ui.py            # 浅色
python scripts/screenshot_ui.py --dark     # 深色
python scripts/screenshot_ui.py --mobile   # 移动端

# 5) 像素审计
python scripts/ui_audit.py                 # 期望：AUDIT_OK
```

截图产物在 `screenshots/`（不纳入版本库，可随时重新生成）。

## 6. 本轮修复的真实缺陷（验证驱动发现）

| # | 现象 | 根因 | 修复 |
|---|------|------|------|
| 1 | 反问环节永远识别不到 | `insert_qa` 未写入 `direction` 列（默认 normal） | 补列并在插入时写入 |
| 2 | 缓存类问题被归到"项目经历/行为问题" | 分类优先级把"项目/行为"关键词排在技术栈之前 | 调整为 系统设计 → 技术栈 → 项目/团队/行为 |
| 3 | 同义问法无法识别相似（仅 0.44 分） | 打分只依赖字面序列相似 | 引入字符集合/领域词/意图词规范化四层加权 |
| 4 | 相似线索在非 AI 模式完全不可见 | 灰区候选未落库 | 灰区记为"疑似"并可人工确认/取消 |
| 5 | 审计指标误报（贴边、深色对比度） | 度量把全宽顶栏算入；对比度方向对深色主题取反 | 修正度量（跳过顶栏、按背景亮暗选择极值方向） |
